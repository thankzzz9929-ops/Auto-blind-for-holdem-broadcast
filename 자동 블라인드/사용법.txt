==============================================
  홀덤 블라인드 타이머 사용법
==============================================

토너먼트 블라인드 타이머입니다.
PC나 안드로이드 폰에서 타이머를 조작하고,
방송 프로그램(PRISM Live Studio, OBS 등)에 블라인드를 띄울 수 있습니다.


■ 내 사이트 주소 (폰·방송 PC에서 이 주소로 열기)
----------------------------------------------
  https://thankzzz9929-ops.github.io/Auto-blind-for-holdem-broadcast/

  폰: 크롬에서 위 주소 열기 → ⋮ → 홈 화면에 추가
  깃허브 저장소: https://github.com/thankzzz9929-ops/Auto-blind-for-holdem-broadcast

  사이트를 고쳤을 때 업데이트하는 법
  1) 위 깃허브 저장소 열기 → Add file → Upload files
  2) 바뀐 index.html 끌어다 놓기 → Commit changes
  3) 1~2분 뒤 사이트 새로고침 (폰 앱은 껐다 켜기)


■ 들어 있는 파일
----------------------------------------------
  index.html            타이머 본체 (이 파일을 엽니다)
  sw.js                 오프라인 실행용
  사용법.txt            이 문서

  ※ 파일을 따로 떼어 쓰지 말고 폴더째로 사용하세요.


■ 1. 가장 간단하게: PC 한 대로 쓰기
----------------------------------------------
  인터넷에 올릴 필요 없이 바로 쓸 수 있습니다.

  1) index.html 을 크롬(또는 엣지)으로 엽니다.
  2) [템플릿 편집] 탭에서 블라인드 구조를 고르거나 만듭니다.
  3) [블라인드 표시] 탭에서 [▶ 시작]을 누릅니다.

  방송에 띄우기:
  4) 아래쪽 [📺 방송용 창] 버튼 → 초록 배경 창이 새로 뜹니다.
  5) 방송 프로그램에서 [창 캡처]로 그 창을 선택합니다.
  6) 필터에서 [크로마키]를 추가하면 초록색이 지워집니다.

  원래 창에서 누르는 조작이 방송용 창에 바로 반영됩니다.
  방송용 창은 최소화하지 말고 다른 창 뒤에 두세요.


■ 조작 방법
----------------------------------------------
  ▶ 시작 / ⏸ 일시정지   타이머 시작·정지 (큰 시계를 눌러도 됨)
  ⏮ 이전 / 다음 ⏭      레벨 이동
  -1분 / +1분           남은 시간 조정
  ↺ 리셋                레벨 1로 처음부터
  오른쪽 구조표         레벨을 누르면 그 레벨로 이동

  PC 단축키
    Space   시작 / 정지
    ← →     이전 / 다음 레벨
    ↑ ↓     +1분 / -1분
    F       전체화면

  알림음: 레벨이 바뀔 때 3번, 1분 남았을 때 1번
          (폰이 백그라운드에 있을 때는 울리지 않습니다)


■ 펍 포스터로 블라인드 불러오기
----------------------------------------------
  [템플릿 편집] 탭 → [🖼 펍 포스터로 불러오기]

  방법 A (API 키 있을 때, 제일 편함)
  1) [🔑 API 키 설정]에 Claude API 키 입력 (한 번만)
     - console.anthropic.com 에서 발급, 포스터 1장당 몇십 원 수준
     - 키는 이 기기 브라우저에만 저장됩니다
  2) 포스터 사진을 누르기/끌어다 놓기/Ctrl+V 로 넣기
  3) [🔍 포스터 읽어서 새 템플릿 만들기] → 10~30초 뒤 새 템플릿 생성

  방법 B (API 키 없이, 무료)
  1) [📋 프롬프트 복사]
  2) Claude 앱에 포스터 사진 + 복사한 프롬프트를 같이 보냄
  3) 받은 답변을 칸에 붙여넣고 [적용]
     (표를 직접 "1 100/200 200 20분", "휴식 10분" 처럼 적어도 됨)

  ※ AI가 숫자를 잘못 읽을 수 있으니, 만들어진 표를 포스터와
    한 번 대조하고 틀린 칸은 고친 뒤 [💾 저장] 하세요.


■ 블라인드 템플릿 만들기
----------------------------------------------
  [템플릿 편집] 탭
  - [⚙ 블라인드 자동 생성]: 시작 BB, 레벨 수, 시간, 증가율,
    앤티 방식, 휴식 간격을 넣고 [생성]을 누르면 구조가 만들어집니다.
  - 표에서 SB / BB / 앤티 / 시간을 직접 고칠 수 있습니다.
    (BB를 입력하면 SB는 절반으로 자동 입력)
  - [+ 레벨 추가] [+ 휴식 추가], ↑↓ 순서 변경, ✕ 삭제
  - 다 고쳤으면 반드시 [💾 저장]
  - [▶ 이 템플릿으로 시작]을 누르면 바로 타이머 화면으로 이동

  다른 기기로 옮기기:
  - [내보내기]로 .json 파일 저장 → 다른 기기에서 [가져오기]
  - 템플릿은 기기(브라우저)마다 따로 저장되므로
    폰과 PC의 템플릿은 자동으로 공유되지 않습니다.
    (연동 중에는 조작 기기의 현재 블라인드가 방송 화면에 그대로 나옵니다)


■ 문제가 생겼을 때
----------------------------------------------
  Q. 방송 화면에 아무것도 안 나와요.
     - 폰 앱에서 [📡 원격 연동] 상태가 "연결됨"인지 확인하세요.
     - 방송 URL의 room= 뒤 코드가 폰 앱의 방 코드와 같은지 확인하세요.
     - 폰에서 아무 버튼(예: 일시정지 → 시작)을 한 번 눌러 보세요.

  Q. 폰과 방송 화면의 시간이 조금 달라요.
     - 폰과 PC의 시계를 기준으로 계산합니다.
       두 기기 모두 날짜/시간 설정에서 "자동 설정"을 켜 주세요.

  Q. 방 코드를 바꿨어요.
     - 방송 프로그램의 웹 소스 URL도 새 URL로 바꿔야 합니다.
